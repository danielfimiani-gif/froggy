# Tópicos Avanzados de Programación

## Trabajo Práctico: Exámen Final

Utilizar Github actions en el proyecto de Frogger de los TPs 2 y 3.

Empezar con el `main.yml` mostrado en clase como base, y utilizar IA (recomendada: claude),
para poder agregar las cosas faltantes.

## Para aprobar (notas del 4 al 6)

- Aplicar al código del Frogger, todas las correcciones realizadas en los TPs 2 y 3.
- Utilizar GitHub Actions para generar una build en **WebGL** automáticamente al hacer push
  del repositorio (generando cache de la carpeta `Library`).

## Para puntos extra

- **Extra 1 (2.5 pts):** Utilizar GitHub Actions para correr los Unit Tests automáticamente
  al hacer push del repositorio.
- **Extra 2 (1.5 pts):** Hacer (en paralelo a la de WebGL) build también en alguna otra
  plataforma a elección.

## Fecha de entrega

Hasta las **18 hrs** del día anterior a la mesa de exámen a la que se anoten.
